# MusicR

## Descripción general

MusicR es un proyecto académico que propone el desarrollo de un reproductor de música digital. El sistema permitirá a los usuarios organizar y reproducir sus canciones, crear playlists y buscar contenido musical.

El proyecto será planificado y gestionado utilizando herramientas como Git, GitHub, GitHub Issues y GitHub Projects.

## Problema que resuelve

Los usuarios pueden tener dificultades para organizar sus canciones y acceder rápidamente a la música que desean escuchar.

MusicR busca ofrecer una solución sencilla para organizar una biblioteca musical, crear playlists y controlar la reproducción de canciones desde una interfaz fácil de utilizar.

## Objetivo

Diseñar y planificar un reproductor de música que permita gestionar una biblioteca musical y facilitar la reproducción y organización de canciones.

## Stack tecnológico propuesto

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Issues
- GitHub Projects

## Planificación del proyecto

El proyecto estará dividido en tres grandes fases o épicas:

### Épica 1 - Gestión de usuarios y biblioteca

Esta fase contempla la gestión básica de usuarios y la organización de la biblioteca musical.

### Épica 2 - Reproducción y playlists

Esta fase contempla las funciones principales del reproductor, incluyendo la reproducción de canciones y la creación de playlists.

### Épica 3 - Búsqueda, configuración y cierre

Esta fase contempla la búsqueda de canciones, configuración del reproductor, pruebas y preparación de la versión final.

## Sprints planeados

- Sprint 1: Configuración y gestión de usuarios
- Sprint 2: Biblioteca musical
- Sprint 3: Reproductor de música
- Sprint 4: Playlists
- Sprint 5: Búsqueda y configuración
- Sprint 6: Pruebas y cierre

## Gestión del proyecto

La planificación y seguimiento del proyecto se realizará mediante GitHub Projects utilizando un tablero Kanban con las siguientes columnas:

- Backlog
- En Progreso
- En Revisión
- Completado

Los requerimientos del proyecto se gestionarán mediante GitHub Issues y las diferentes fases se organizarán mediante GitHub Milestones.
